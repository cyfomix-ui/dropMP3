DropMp3 Install方法

通常の音楽再生だけなら追加ツールは不要です。字幕作成や詳細情報表示を使う場合だけ、必要なものをインストールしてください。

Python / 必須ライブラリ

python -m pip install --upgrade pip
python -m pip install --upgrade PySide6 mutagen pyinstaller

Whisper

python -m pip install -U openai-whisper
whisper --help

FFmpeg / ffprobe

winget install Gyan.FFmpeg
ffmpeg -version
ffprobe -version

設定ファイル

設定はレジストリではなく _conf\DropMp3.ini に保存されます。

Help HTML は _conf\html、プレイリストは _conf\lst に配置されます。

字幕ファイルは _conf\srt に保存されます。Both 指定時は .srt と .srt2 を作成します。

[General]
volume=0.8
playlist_json=[]
