DropMp3 Operation Guide

Playback

  • Drop audio files, folders, or M3U8/WPL playlists onto the window to add and play them.
  • Click the album art to toggle play and pause.
  • Use the mouse wheel to adjust volume.
  • Drag the bottom slider to seek.

Playlist

  • Use the side menu button to open or close the playlist.
  • Use 📋 to choose and load a saved playlist from _conf\lst.
  • Use 💾 to save a playlist with a timestamped file name.
  • Use 🔍 to search the current playlist. Leave it blank to show all items again.
  • Right-click playlist items for properties, subtitle checks, subtitle deletion, and removal.

Playback Modes

  • 🔀 shuffles the playlist. 📁 sorts it by file name.
  • 🔁 cycles repeat mode through Off, One, and All.
  • 🎯 enables one-shot playback without adding the file to the playlist.

Subtitles

  • Right-click a playlist item to request subtitles, check SRT files, or delete subtitles.
  • The subtitle request dialog lets you choose source language and target output. Both creates .srt and .srt2.
  • The subtitle icon cycles through Off, primary subtitle, and secondary subtitle.
  • Subtitle files are saved under _conf\srt.
  • Whisper is used for subtitle creation, Ollama for translation, and FFmpeg/ffprobe for detailed media information.
