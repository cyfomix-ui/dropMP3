DropMp3 Install Guide

Basic music playback does not require extra command-line tools. Install the optional tools only when you need subtitle creation or detailed media information.

Python / Required Libraries

python -m pip install --upgrade pip
python -m pip install --upgrade PySide6 mutagen pyinstaller

Whisper

python -m pip install -U openai-whisper
whisper --help

FFmpeg / ffprobe

winget install Gyan.FFmpeg
ffmpeg -version
ffprobe -version

Settings File

Settings are stored in _conf\DropMp3.ini instead of the registry.

Help HTML files are placed in _conf\html, and playlists are placed in _conf\lst.

Subtitle files are saved under _conf\srt. When Both is selected, DropMp3 creates .srt and .srt2.

[General]
volume=0.8
playlist_json=[]
