# DropMp3 機能トピック

作成日: 2026-05-31  
対象版: i18n / Splash / OneShot拡張 / Playlist I/O / 複数選択対応版

## 概要

DropMp3 は、ドラッグ＆ドロップ操作を中心にした Windows 向け小型音楽プレイヤーです。

MP3 などの音楽再生だけでなく、ジャケット画像表示、字幕表示、プレイリスト編集、ミニ表示、タスクトレイ格納、ワンショット再生、ランダムジャケット表示、ffprobe / Whisper 連携、プレイリストファイルの入出力、外部アプリとのドラッグ＆ドロップ連携に対応します。

---

## 1. 日本語 / 英語 UI 自動切り替え

Windows の表示言語が日本語の場合は日本語 UI、日本語以外の場合は英語 UI で表示します。

ボタン、ツールチップ、確認メッセージ、右クリックメニュー、Whisper 進捗画面などの主要 UI 文言を切り替えます。

環境変数で強制切り替えもできます。

```powershell
$env:DROPMP3_UI_LANG="ja"
python .\dropMp3.py

$env:DROPMP3_UI_LANG="en"
python .\dropMp3.py
```

---

## 2. 起動時 Splash と進捗表示

起動時に経過表示 Splash を表示します。

本体ウィンドウが出るまで、設定復元、プレイリスト確認、UI 構築、前回曲復元などの処理状況を表示します。

PyInstaller の OneFile 配布では、`--splash` を使うことで Python / Qt 起動前の待ち時間にも簡易 Splash を表示できます。

---

## 3. ドラッグ＆ドロップ即時再生

音楽ファイルをウィンドウにドロップすると、すぐに再生できます。

複数ファイルをまとめてドロップすると、プレイリストへ追加されます。

フォルダをドロップした場合は、対応音楽ファイルを走査して追加します。

---

## 4. 対応音声ファイル

主な対応拡張子は以下です。

```text
.mp3
.wav
.flac
.ogg
.m4a
.aac
.wma
.aiff
.aif
```

実際の再生可否は Qt Multimedia / FFmpeg バックエンドの対応状況に依存します。

---

## 5. プレイリスト管理

左ドロワーにプレイリストを表示できます。

再生中の曲はオレンジで強調表示されます。
字幕ファイルが存在する曲は青文字で表示されます。

プレイリストでは以下の操作が可能です。

- 曲をクリックして再生
- `Ctrl + クリック` で複数選択
- `Shift + クリック` で範囲選択
- Delete キーで選択曲を削除
- 複数選択曲をまとめて削除
- ドラッグ＆ドロップで曲順変更
- 複数選択曲をまとめて内部移動
- シャッフル
- ファイル順並び替え
- `Off / 1曲 / 全曲` のリピート再生
- リスト右クリックからプロパティ表示
- リスト右クリックから字幕依頼
- リスト右クリックから字幕確認
- リスト右クリックから字幕削除

---

## 6. プレイリストファイルの Drop 読み込み

エクスポート済みのリストファイルを Drop して、プレイリストへ追加できます。

対応するリスト形式は以下です。

```text
.m3u
.m3u8
.wpl
.pls
.txt
.list
.playlist
```

`.txt` / `.list` / `.playlist` は、フルパスが複数行で並んでいるテキストをリストとして読み込みます。

例:

```text
D:\Music\song1.mp3
D:\Music\song2.flac
"D:\Music\song with space.m4a"
```

空行、`#` で始まる行、`;` で始まる行は無視します。

---

## 7. リストファイルの Drop 位置

左リスト上にリストファイルを Drop した場合は、その Drop 位置へ挿入追加します。

ジャケット画像側や本体側へリストファイルを Drop した場合は、確認ダイアログを表示します。

- 追加挿入
- 置換挿入
- 取消

これにより、現在のリストへ足すのか、現在のリストを置き換えるのかを選べます。

---

## 8. プレイリスト保存

曲名タイトル段の左側に、リスト保存アイコンを配置しています。

保存時はファイル名の拡張子で形式を判定します。

```text
playlist.m3u8 → M3U8 形式で保存
playlist.wpl  → WPL 形式で保存
```

拡張子なしで保存した場合は、保存ダイアログで選んだフィルタに合わせて拡張子を補います。

---

## 9. リストクリア

曲名タイトル段の左側に、リストクリアアイコンを配置しています。

押した直後に消すのではなく、確認ダイアログを表示します。

OK した場合だけ、現在のプレイリストをクリアします。

---

## 10. 外部アプリへの Drag & Drop

左リストの曲を Explorer へドラッグした場合、実ファイルをコピーできる形式で渡します。

Editor などテキストを受け取るアプリへドラッグした場合は、ファイルのフルパスをテキストとして渡します。

複数選択した場合は、複数ファイル URL と、改行区切りのフルパス文字列を渡します。

---

## 11. 左ドロワー UI

ChatGPT 風の左側ドロワーを採用しています。

三本線アイコンで開閉できます。

リストクリア / リスト保存アイコンはタイトル段の左側に配置し、三本線アイコンは従来の縦レール側に配置しています。

ドロワーの開閉状態は保存されます。

---

## 12. スプリッター対応

左リストとジャケット表示の間にスプリッターがあります。

リストを広くしたり、ジャケットを大きく表示したりできます。

スプリッター位置は保存され、次回起動時に復元されます。

---

## 13. ジャケット画像表示

音楽ファイルに埋め込まれているアルバムアートを表示します。

ウィンドウサイズに合わせて可能な範囲で大きく表示します。

曲名タイトルは 28px で表示します。

---

## 14. ミニプレイヤー / アイコンモード

ジャケット画像をダブルクリックすると、小型のミニプレイヤー表示になります。

ミニプレイヤー中も、再生 / 一時停止、次曲、時間確認、ワンショットアイコン、フォントアイコンなどを利用できます。

ミニプレイヤーから通常表示へ戻るときは、ダブルクリック直後のシングルクリック誤判定で曲が停止しないように対策しています。

---

## 15. タスクトレイ格納

通常プレイヤーの最小化ボタンを押すと、タスクバーではなくタスクトレイへ格納できます。

タスクトレイのアイコンをダブルクリックすると通常プレイヤーへ戻ります。

ミニプレイヤーのダブルクリックは、タスクトレイ化ではなく通常プレイヤーへの復帰に使います。

---

## 16. ワンショット再生

ターゲット風アイコンでワンショット再生モードを切り替えできます。

ワンショット再生では、ドロップした曲をプレイリストへ追加せず、その場で一時再生します。

素材確認、効果音確認、AI 生成曲の一時確認などに向いています。

ワンショット終了後は約 0.3 秒待って、通常再生へ復帰します。

---

## 17. ワンショットアイコンへの直接 Drop

通常画面とミニプレイヤーの両方で、ワンショットアイコンへ音楽ファイルを直接 Drop できます。

音楽ファイルをドラッグしてアイコン上に乗せると、アイコンが一時的に拡大され、Drop 位置が分かりやすくなります。

ツールチップには以下を表示します。

```text
このアイコンに音楽ファイルをDropするとワンショットで再生されます
Drop an audio file on this icon to play it as a one-shot.
```

---

## 18. 字幕表示

同名の `.srt` ファイルを自動検索し、再生時間に合わせて字幕を表示します。

検索対象は以下です。

```text
音楽ファイルと同じフォルダ
音楽ファイル側の srt / SRT フォルダ
起動 EXE 側の srt / SRT フォルダ
```

SRT は UTF-8 と Shift_JIS の読み込みに対応しています。

現在行は緑、前後行は白で表示されます。

---

## 19. 字幕確認 / 字幕削除

左リスト上の右クリックメニューに、字幕関連操作があります。

並びは以下です。

```text
プロパティ
――――
字幕依頼
字幕確認
字幕削除
```

字幕確認では、対象曲に対応する `.srt` を探し、見つかった場合は Notepad で開きます。

字幕削除では、確認ダイアログの後に対象字幕ファイルを削除します。

---

## 20. ffprobe / Whisper 連携

### プロパティ

`ffprobe` がある場合、選択曲のメディア情報を取得して別ウィンドウで表示します。

### 字幕依頼

`Whisper` がある場合、音楽再生とは別プロセスで SRT 字幕作成を実行できます。

進捗ウィンドウで処理状況を確認できます。

---

## 21. 音量、シーク、基本操作

再生 / 一時停止、前曲 / 次曲、シークバー、音量ホイール操作に対応しています。

音量表示またはジャケット画像上でマウスホイールを回すと音量変更できます。

---

## 22. ランダムジャケット表示

`Random` チェックを ON にすると、プレイリスト内の他曲の画像も使ってランダム表示できます。

曲開始直後はオリジナル画像を表示し、その後一定間隔でランダム画像へ切り替えます。

---

## 23. ログウィンドウ

`F12` でログウィンドウを表示できます。

起動情報、Python 実行環境、Qt Multimedia / FFmpeg バックエンド情報、再生状態、字幕検索、エラーなどを確認できます。

---

## 24. 想定用途

DropMp3 は以下の用途に向いています。

- AI 生成曲の確認
- Suno / ACE-Step などで作った曲の整理
- 歌詞 SRT 付き音源の確認
- 効果音の一時確認
- BGM 再生
- ジャケット画像付き音源の視聴
- 他アプリへのファイルパス受け渡し
- プレイリスト作成前の仮並べ
