# DropMp3 使い方ガイド

作成日: 2026-05-31  
対象版: i18n / Splash / OneShot拡張 / Playlist I/O / 複数選択対応版

## 1. DropMp3とは

DropMp3 は、音楽ファイルをドラッグ＆ドロップするだけで再生できる Windows 向け小型音楽プレイヤーです。

ジャケット画像表示、プレイリスト編集、字幕表示、ワンショット再生、ミニ表示、タスクトレイ格納、ランダムジャケット表示、ffprobe によるプロパティ確認、Whisper による字幕作成依頼、プレイリストファイルの読み書き、外部アプリへのドラッグ＆ドロップ連携に対応しています。

---

## 2. 起動方法

### EXE版の場合

`DropMp3.exe` をダブルクリックして起動します。

OneFile 配布版では、起動直後に PyInstaller 側の Splash が表示される場合があります。

その後、DropMp3 本体側の経過表示 Splash が表示され、本体ウィンドウが起動します。

### Python版の場合

必要なライブラリを入れたうえで、PowerShell またはコマンドプロンプトから実行します。

```powershell
python .\dropMp3.py
```

日本語 / 英語 UI を強制したい場合は以下を使います。

```powershell
$env:DROPMP3_UI_LANG="ja"
python .\dropMp3.py

$env:DROPMP3_UI_LANG="en"
python .\dropMp3.py
```

---

## 3. 音楽ファイルの再生

ウィンドウに音楽ファイルをドラッグ＆ドロップすると、すぐに再生されます。

複数ファイルをまとめてドロップした場合は、プレイリストに追加されます。

フォルダをドロップした場合は、フォルダ内の対応音楽ファイルを読み込みます。

左ドロワーのリスト部分へドロップした場合は、ドロップ位置に追加できます。

ジャケット画像側へドロップした場合は、基本的にリスト末尾へ追加されます。

---

## 4. 対応している主な音楽ファイル

```text
.mp3
.wav
.flac
.ogg
.m4a
.aac
.wma
.aiff
.aif
```

---

## 5. 基本操作

### 再生 / 一時停止

中央の再生ボタンを押すと再生します。

再生中に押すと一時停止します。

ジャケット画像上でクリックしても、再生 / 一時停止できます。

### 前の曲 / 次の曲

再生ボタンの左右にあるボタンで、前の曲・次の曲へ移動できます。

### シークバー

画面下部のバーをドラッグすると、再生位置を変更できます。

左側に現在時間、右側に曲全体の時間が表示されます。

---

## 6. 音量操作

再生コントロール左側に現在の音量が表示されます。

音量表示の上にマウスを置き、マウスホイールを回すと音量を変更できます。

ジャケット画像の上でマウスホイールを回しても音量変更できます。

---

## 7. 左ドロワーのプレイリスト

左端の三本線ボタンを押すと、プレイリストを開閉できます。

プレイリストでは以下の操作ができます。

- 曲をクリックして再生
- `Ctrl + クリック` で複数曲を個別選択
- `Shift + クリック` で範囲選択
- Delete キーで選択曲を削除
- 選択した複数曲をまとめて削除
- ドラッグ＆ドロップで曲順を入れ替え
- 複数選択曲をまとめて移動
- シャッフルボタンでランダム並び替え
- フォルダ / ファイル順ボタンで並び替え
- リピートボタンで `Off / 1曲 / 全曲` を切り替え
- 右クリックメニューからプロパティ、字幕依頼、字幕確認、字幕削除を実行

再生中の曲はオレンジ色で表示されます。

字幕ファイルが見つかっている曲は青文字で表示されます。

ドロワー下部には `10/500` のように、現在再生中の曲番号 / 全曲数が表示されます。

---

## 8. リストクリアとリスト保存

曲名タイトル段の左側に、リストクリアアイコンとリスト保存アイコンがあります。

### リストクリア

リストクリアアイコンを押すと確認ダイアログが表示されます。

OK した場合のみ、現在のプレイリストをクリアします。

### リスト保存

リスト保存アイコンを押すと保存ダイアログが開きます。

ファイル名の拡張子に合わせて保存形式が決まります。

```text
playlist.m3u8 → M3U8形式
playlist.wpl  → WPL形式
```

拡張子なしの場合は、保存ダイアログで選択したフィルタに合わせて補われます。

---

## 9. プレイリストファイルの読み込み

以下のリストファイルを Drop して読み込めます。

```text
.m3u
.m3u8
.wpl
.pls
.txt
.list
.playlist
```

左リスト上に Drop した場合は、その曲間に挿入追加されます。

ジャケット画像側や本体側に Drop した場合は、確認ダイアログが表示されます。

- 追加挿入
- 置換挿入
- 取消

`追加挿入` は現在のリストに追加します。

`置換挿入` は現在のリストを置き換えます。

`取消` は何もしません。

---

## 10. フルパス一覧テキストの読み込み

`.txt` / `.list` / `.playlist` は、複数行のフルパス一覧として読み込めます。

例:

```text
D:\Music\song1.mp3
D:\Music\song2.flac
"D:\Music\song with space.m4a"
```

空行、`#` で始まる行、`;` で始まる行は無視されます。

Editor などからフルパス一覧テキストを直接 Drop した場合も、読み取れる範囲でプレイリストとして処理します。

---

## 11. 外部アプリへ曲をドラッグする

左リストの曲を Explorer へドラッグすると、実ファイルをコピーできる形式で渡します。

左リストの曲を Editor などへドラッグすると、ファイルのフルパスをテキストとして挿入できる形式で渡します。

複数選択した曲をドラッグした場合は、複数ファイルとして渡し、テキストとしては改行区切りのフルパスを渡します。

---

## 12. スプリッターによる表示調整

左リストとジャケット画像の間にはスプリッターがあります。

スプリッターをドラッグすると、リストとジャケット画像の幅を調整できます。

ウィンドウ位置、サイズ、スプリッター位置は終了時に保存され、次回起動時に復元されます。

---

## 13. ワンショット再生

右側のターゲット風アイコンを押すと、ワンショット再生モードを切り替えできます。

ワンショットモード中にファイルをドロップすると、プレイリストに追加せず、その曲だけを再生します。

通常再生中にワンショット再生した場合、ワンショット終了後に約 0.3 秒待って通常再生へ戻ります。

---

## 14. ワンショットアイコンへの直接 Drop

通常画面とミニプレイヤーの両方にワンショットアイコンがあります。

音楽ファイルをワンショットアイコンへ直接 Drop すると、その場でワンショット再生します。

ドラッグ中にアイコン上へ乗せると、アイコンが拡大して Drop 先が分かりやすくなります。

ツールチップには以下が表示されます。

```text
このアイコンに音楽ファイルをDropするとワンショットで再生されます
Drop an audio file on this icon to play it as a one-shot.
```

---

## 15. 字幕表示

音楽ファイルと同名の `.srt` ファイルがある場合、再生時間に合わせて字幕を表示します。

検索場所は以下です。

```text
音楽ファイルと同じフォルダ
音楽ファイルと同じフォルダ内の srt フォルダ
音楽ファイルと同じフォルダ内の SRT フォルダ
起動 EXE と同じフォルダ内の srt フォルダ
起動 EXE と同じフォルダ内の SRT フォルダ
```

SRT は UTF-8 と Shift_JIS の読み込みに対応しています。

現在の字幕行は緑色で表示され、前後の字幕は白で表示されます。

字幕パネル右上の `×` を押すと字幕を閉じられます。

閉じたあと、ジャケット右下の字幕アイコンを押すと再表示できます。

---

## 16. 字幕依頼 / 字幕確認 / 字幕削除

左ドロワーのリスト上で曲を右クリックすると、選択曲向けメニューが表示されます。

```text
プロパティ
――――
字幕依頼
字幕確認
字幕削除
```

### 字幕依頼

Whisper がインストールされている場合、選択した音楽ファイルの SRT 字幕作成を別プロセスで開始します。

処理中は進捗ウィンドウが表示されます。

### 字幕確認

対応する `.srt` が見つかった場合、Notepad で開きます。

### 字幕削除

対応する `.srt` が見つかった場合、確認ダイアログの後に削除します。

---

## 17. アイコンモード / ミニプレイヤー

ジャケット画像をダブルクリックすると、小型のミニプレイヤーになります。

ミニプレイヤーでは、ジャケット画像、曲名、再生 / 一時停止、次曲、フォントアイコン、ワンショットアイコンなどを使えます。

ミニプレイヤーのジャケット画像をもう一度ダブルクリックすると通常表示へ戻ります。

ダブルクリックで通常表示へ戻った直後に、シングルクリック扱いで曲が停止しないように対策されています。

---

## 18. タスクトレイ格納

通常プレイヤーでウィンドウ右上の最小化ボタンを押すと、タスクバーから消えてタスクトレイへ格納されます。

タスクトレイの DropMp3 アイコンをダブルクリックすると、通常プレイヤーへ戻ります。

---

## 19. ランダムジャケット表示

タイトル行右側の `Random` チェックを ON にすると、ジャケット画像をランダム表示できます。

再生開始直後は曲に埋め込まれているオリジナル画像を表示し、その後、プレイリスト内の画像からランダムに切り替えます。

音楽を一時停止すると、ランダム画像の自動切り替えも停止します。

---

## 20. 右クリックメニュー

ウィンドウ上で右クリックすると、簡易プレイリストと終了メニューが表示されます。

左ドロワーが開いている場合は、重複を避けるため、右クリック側のリスト表示は抑止されます。

左ドロワーのリスト上で曲を右クリックすると、選択曲向けのメニューが表示されます。

---

## 21. 歯車メニュー

右端の歯車アイコンから各種操作を開けます。

主な項目は以下です。

- WPL リストファイル作成
- M3U8 リストファイル作成
- リストクリア
- ログウィンドウ表示 / 非表示
- 並び替え・リピート関連操作

---

## 22. ログウィンドウ

`F12` キーを押すとログウィンドウを表示 / 非表示できます。

ログには、起動情報、Qt Multimedia / FFmpeg 情報、再生状態、字幕検索、エラーなどが記録されます。

---

## 23. 外部ツールを使う機能

### ffprobe

リスト上の右クリックメニューから「プロパティ」を使う場合に利用します。

音声形式、ビットレート、長さ、タグ、埋め込み画像などの詳細確認に使えます。

### Whisper

リスト上の右クリックメニューから「字幕依頼」を使う場合に利用します。

生成された `.srt` は、音楽ファイルと同名で保存しておくと、次回以降の再生時に自動検出されます。

---

## 24. 終了方法

右クリックメニューの一番下にある「終了」を押すと、アプリを終了します。

ウィンドウ位置、サイズ、スプリッター位置、プレイリスト、再生中の曲、再生位置、ドロワー状態などは保存されます。
